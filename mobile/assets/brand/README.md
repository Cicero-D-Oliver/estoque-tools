# Identidade mobile

`estoque-tools-icon-master.svg` é o arquivo mestre do ícone. Ele preserva o mesmo símbolo `Boxes` usado pelo frontend web, sobre o gradiente azul da marca.

`estoque-tools-symbol.svg` contém a versão branca e transparente usada no ícone adaptativo, no ícone monocromático e no splash. Os PNGs em `assets/` são exportações de 1024 × 1024 desses vetores, sem arredondamento ou texto; o Android aplica a máscara apropriada no launcher.

A geometria `Boxes` vem do Lucide, sob licença ISC, dependência já utilizada pelo frontend do projeto.
